# 原始串口日志：新版 BIN 用法与 Qt 读取

更新日期：2026-11-07。分支：`feature/uart-raw-logger`。

## 新版变化

新版只记录原始串口字节，不记录时间戳，不解析设备协议。USB 磁盘上的新日志只有 `00000001.BIN`、`00000002.BIN` 等，以及辅助状态文件 `STATUS.TXT`。

**BIN 的第一个字节就是收到的第一个有效字节。没有文件头、长度字段、分隔符、时间戳、CRC 或页填充。** 顺序保留，所有值（包括 `00`、`FF`、回车换行）原样导出。丢失的字节不补占位符。

Qt 不再需要旧的 ULG 容器解析器。旧 v1/v2 日志仍能下载 BIN 和 ULG，新旧日志可以共存；原《UART日志格式与Qt解析说明》中的 ULG 字段表仅用于旧日志。

## 记录和下载

配置与此前相同，例如：

```text
set uart_logger_uart = UART1
set uart_logger_baud = 115200
set uart_logger_parity = 0
set uart_logger_stop_bits = 1
set blackbox_device = SPIFLASH
save
```

串口需空闲，发送端 TX 接飞控对应 RX 并共地。UART1 的 RX 为 PA10；如已使用其他串口，保留原设置即可。

- 每次正常启动新建日志，编号递增；进入下载模式不创建新日志。
- 空间不足或达到 32 份日志上限时删除最旧的整份日志。
- 长日志到达半个 Flash 容量或物理末尾时自动分段，继续使用下一编号。
- 进入 CLI 停止接收并保存缓冲数据；输入 `msc`，从 `BETAFLT` 磁盘复制 BIN。
- 下载后正常重启开始下次录制，无需每次 `flash_erase`。擦除会删除全部日志并重置编号。

## 空间和断电行为

Flash 内部仍需要少量管理信息，以便重启后识别日志边界、长度和编号。每个物理页末尾保留 16 字节管理信息，USB 导出时自动去除；不再使用旧版每 64 字节最多容纳 44 字节数据的格式。

| 物理页大小 | 每页原始数据 | 满页数据占比 |
| --- | --- | --- |
| 2048 字节 | 2032 字节 | 99.22% |
| 256 字节 | 240 字节 | 93.75% |

以上不含每份日志的头部页、结束页和扇区空隙。时间取决于实际每秒收到多少字节；例如 16 MiB、2048 字节页、115200 波特率 8N1 持续满速，理想打包容量约 24.1 分钟，实际循环保留时长还受整份旧日志淘汰影响。

为避免低速输入大量浪费空间，不满一页的数据先留在 RAM，不再定时生成小记录。**突然断电会丢失尚未落盘的接收缓冲、待写页和 Flash 写入尾部；少于一页的短录制可能完全没有保存数据。** 下载前进入 CLI/`msc` 会停止接收并写完不足一页的数据。需要保证短日志时，应正常停止后再断电。

`STATUS.TXT` 的完整状态与 dropped 分开理解：完整表示正常封口，不代表零丢失；dropped 是本次开机累计的软件丢弃计数，不是当前文件单独计数，也不统计所有 UART 硬件错误。断电后该计数可能停留在最后成功保存的页。

## Qt 读取

使用 `QFile` 二进制读取，不设置 `QIODevice::Text`，也不要先转 QString。

```cpp
QFile file(path);
if (!file.open(QIODevice::ReadOnly)) {
    // 显示 file.errorString()，终止导入。
    return;
}
while (!file.atEnd()) {
    const QByteArray bytes = file.read(64 * 1024);
    if (file.error() != QFileDevice::NoError) {
        // 显示读错误，标记导入未完成。
        return;
    }
    // hexModel.append(bytes);       // 原始十六进制查看。
    // deviceParser.feed(bytes);     // 交给实际设备协议解析器。
}
```

这只是读取示意，`hexModel` 和 `deviceParser` 由 Qt 工程实现。大日志建议后台分块读取、按需显示，避免一次生成所有十六进制文本。

设备帧可能跨任意两次 `read()`，协议解析器必须保留未完成帧。文件中没有帧边界信息，也没有电压、电流、转速的字段定义；这些必须按发送设备的协议解码。

如果发送设备自己的数据没有时间戳，只能按字节偏移或帧序号显示；不可把字节数除以波特率当成真实接收时间，因为发送端可能有任意空闲间隔。不同文件编号连续不保证属于同一次开机；拼接前应由使用者确认。

## 内部维护参考

内部格式号已升级为 3，技术布局见同目录 `UartRawLogger.md` 的 Internal Format Version 3。Qt 只读取下载的 BIN 时无需实现它。旧版 Python ULG 转换器仅用于 v1/v2；BIN 已经是原始流，无需再转换。
